# runSubagent Tool

## Описание

Инструмент `runSubagent` предназначен для запуска субагента с указанным именем и передачи ему входных данных для обработки.

## Сигнатура

```typescript
runSubagent(name: string, input: string): Promise<SubagentResponse>
```

### Параметры

- **name** (string, обязательный): Имя субагента, который необходимо запустить
- **input** (string, обязательный): Входной запрос или данные, которые будут переданы субагенту для обработки

### Возвращаемое значение

Функция возвращает Promise, который резолвится в ответ субагента.

## Примеры использования

### Пример 1: Базовое использование

```javascript
// Запуск субагента с простым запросом
const result = await runSubagent('time-agent', 'Сколько времени в Лондоне, Великобритания?');
console.log(result);
```

### Пример 2: Использование в конфигурации агента

```json
{
  "initial_message": "Запустите субагента 'time-agent' с помощью инструмента runSubagent и передайте запрос: 'Сколько времени в Лондоне, Великобритания?'."
}
```

### Пример 3: Использование с разными типами запросов

```javascript
// Запрос текущего времени
await runSubagent('time-agent', 'Какое время в Токио?');

// Запрос информации о погоде
await runSubagent('weather-agent', 'Какая погода в Париже?');

// Запрос перевода
await runSubagent('translation-agent', 'Переведи "Hello World" на русский язык');
```

## Обработка ошибок

При использовании `runSubagent` рекомендуется обрабатывать возможные ошибки:

```javascript
try {
  const result = await runSubagent('my-agent', 'Sample query');
  console.log('Success:', result);
} catch (error) {
  console.error('Error running subagent:', error);
}
```

## Возможные ошибки

- **SubagentNotFound**: Субагент с указанным именем не найден
- **InvalidInput**: Переданный входной параметр имеет неверный формат
- **SubagentTimeout**: Субагент не ответил в течение установленного времени ожидания
- **SubagentError**: Внутренняя ошибка при выполнении субагента

## Примечания

1. Имя субагента должно соответствовать существующему агенту в системе
2. Входные данные должны быть корректно отформатированы в соответствии с требованиями конкретного субагента
3. Время выполнения может варьироваться в зависимости от сложности запроса и загрузки системы
4. Рекомендуется использовать осмысленные имена субагентов для лучшей читаемости кода
